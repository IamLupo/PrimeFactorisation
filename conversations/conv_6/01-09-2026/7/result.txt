====================================================================================================
ALGEBRAIC IDENTITY
====================================================================================================

    p = r1*k + a
    q = r2*l + b

    n = p*q

      = (r1*k+a)(r2*l+b)

      = r1*r2*k*l
        + r1*k*b
        + r2*l*a
        + a*b

    Let:

        R = r1*r2
        K = k*l

    Then:

        n = R*K + r1*k*b + r2*l*a + a*b

    Therefore:

        floor(n/R) = K + floor((r1*k*b + r2*l*a + a*b)/R)

    Hence:

        E = floor(n/R) - K

    This identity is exact.

====================================================================================================
IMPORTANT OBSERVATION
====================================================================================================

The experiment does NOT prove that E <= 1001.

It only tests whether E happens to remain in that
small range for the generated cases.

The proposed search is therefore:

    Q = floor(n/(r1*r2))
    for candidate K:
        E = Q-K
        if 0 <= E <= E_MAX:
            lookup K -> (k,l)
            solve a,b
