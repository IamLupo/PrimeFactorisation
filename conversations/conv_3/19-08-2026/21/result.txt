EXPERIMENT 398 START
==============================================================================================================

EXACT FACTOR-GAP / SHIFTED-FACTOR QUADRATIC RECONSTRUCTION

Objective:
  1. Start from the compressed variable:
       d = sqrt(-4K - 3N^2 + 6N + 1)
  2. Recover:
       S = p+q = (N+1-d)/2
  3. Introduce the factor-gap variable:
       g = q-p
  4. Verify:
       g^2 = S^2 - 4N
  5. Verify the equivalent compressed identity:
       (N+1-d)^2 - 16N = 4g^2
  6. Use d+3 = (p-2)(q-2).
  7. Construct the shifted factor quadratic:
       Y^2 - (S-4)Y + (d+3) = 0
     whose roots should be p-2 and q-2.
  8. Recover p and q exactly from N and d.
  9. Determine whether the smaller shifted branch is always p-2.
 10. Measure whether the factor-gap representation is simpler
     than the original N,K quadratic.

No resultants are constructed.
No symbolic multivariate factorization is performed.
Only exact integer arithmetic is used.
