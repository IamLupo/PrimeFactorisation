  d0_true is NEVER used to construct a bound
  x_true is NEVER used to construct a bound
  no giant K enumeration
  no giant d0 enumeration
  no CRT Cartesian product
  integer-exact

EXACT PULLBACK FORMULA

  K_low <= K <= K_high

      <=>

  d^2 + 4K_low - r
       <= d0^2 <=
  d^2 + 4K_high - r

  Therefore the exact candidate count is obtained from
  integer square roots plus the required parity.

  No candidate K values are enumerated.
  No candidate d0 values are enumerated.

INTERPRETATION

  Experiment 448 showed that the bare quadratic relation
  leaves a parity-compatible d0 family.

  Experiment 449 asks whether an EXTERNAL K bound can
  collapse that family.

  A useful result is not merely a small population.
  The K interval itself must be independently justified.

  A diagnostic interval such as
      |K| < 2^72
  measures computational narrowing but is not a proof
  unless that bound follows independently from the
  available public data.

  The same applies to scales such as
      |K| <= N
      |K| <= N*S
      |K| <= N^2.

IMPORTANT

  If one of these genuinely independent K bounds produces
  a tiny d0 population, that is the next object to inspect.

  If every independently justified bound still produces
  a large d0 population, then the obstruction is an
  information bound rather than an enumeration problem.
