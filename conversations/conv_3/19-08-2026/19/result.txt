EXACT DISCRIMINANT COMPRESSION / SHIFTED FACTORIZATION

Objective:
  1. Introduce the shifted discriminant variable:
       d = N - 2S + 1
  2. Eliminate S exactly from K.
  3. Verify the compressed identity:
       4K + 3N^2 - 6N - 1 = -d^2
  4. Verify:
       d = (p-1)(q-1) - (p+q)
  5. Test the shifted factor form:
       d + 3 = (p-2)(q-2)
  6. Recover d exactly from N and K.
  7. Recover S exactly from N and d.
  8. Recover X = S+1 exactly.
  9. Verify the complete N,K -> d -> S -> X chain.
 10. Determine whether the new expression is simpler than
     the previous quadratic/discriminant representation.

EXPERIMENT 396 FINAL STATUS
==============================================================================================================

The corrected S-level structure admits a further exact
compression by defining:

  d = N - 2S + 1

Then:

  K = -(3N^2 - 6N + d^2 - 1)/4

equivalently:

  4K + 3N^2 - 6N - 1 = -d^2

and therefore:

  d = sqrt(-4K - 3N^2 + 6N + 1)

with the exact branch reconstruction:

  S = (N+1-d)/2
  X = (N+3-d)/2

For the tested semiprimes:

  d = (p-1)(q-1) - (p+q)
    = (p-2)(q-2) - 3

Thus the remaining structural question is whether
this compressed square relation reveals a simpler
N,K invariant or merely repackages the same quadratic.
