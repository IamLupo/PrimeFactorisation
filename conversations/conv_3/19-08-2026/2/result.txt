==============================================================================================================
EXPERIMENT: UNIVERSAL X-DIRECTIONAL ORACLE
==============================================================================================================

GOAL
  For many independent semiprimes N=p*q, test whether:

    X_guess < X_true  =>  kappa residual < 0
    X_guess > X_true  =>  kappa residual > 0

  and independently:

    X_guess < X_true  =>  layer residual > 0
    X_guess > X_true  =>  layer residual < 0

  We also test whether the true X is the only nearby value
  producing a square discriminant.
