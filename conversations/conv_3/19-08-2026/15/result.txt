EXACT KAPPA -> X QUADRATIC COLLAPSE

Objective:
  1. Transform the Kappa quadratic from t=N/X into an exact
     quadratic directly in X.
  2. Verify that X_TRUE is one exact root.
  3. Recover the second X-root exactly.
  4. Verify the X-root Vieta relations.
  5. Analyze the exact X discriminant.
  6. Test whether the smaller X-root is universally X_TRUE.
  7. Test the exact relation between the X discriminant
     and (p-1)(q-1).
  8. Rewrite the layer variable t=N/X and verify the
     two-root layer branches directly in the X domain.

EXPERIMENT 392 FINAL STATUS
==============================================================================================================

The central transformation tested is:

  t = N/X

which converts:

  (K+N^2+2)t^2 - N(N+3)t + N^2 = 0

into:

  X^2 - (N+3)X + (K+N^2+2) = 0

Therefore:

  X1 + X2 = N+3
  X1*X2 = K+N^2+2

and:

  Delta_X = (N+3)^2 - 4(K+N^2+2)
          = (X1-X2)^2

For the tested semiprimes:

  X_TRUE  = p+q+1
  X_OTHER = N+3-X_TRUE
  X_OTHER-X_TRUE = (p-1)(q-1)

The experiment therefore tests whether the hidden X is
systematically the smaller branch of the exact Kappa
quadratic, and whether the layer remains structurally
well-defined after moving completely from t to X.
