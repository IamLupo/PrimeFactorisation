The central test is now:

    F_(z+1)(x/2,y/2)
        =
    F_z(x,y)

This is stronger than merely observing that x and y halve.

If exact for p and q over all levels, then:

    the FUNCTION changes
        only because
    the COORDINATE SCALE changes.

In other words:

    F_2
       |
       | x -> x/2
       | y -> y/2
       v
    F_3
       |
       | x -> x/2
       | y -> y/2
       v
    F_4
       |
       ...

The residue tree is tested separately.

The discarded low bit is also tested:

    x_z = 2*x_(z+1) + epsilon

to determine whether:

    epsilon
        ->
    child residue

is the branch-selection mechanism.

This directly tests the proposed hierarchical transformation:

    A1
      -> B1 or B2

    A2
      -> B3 or B4

where the child functions are related by a static coordinate
renormalization rather than being unrelated equations.
