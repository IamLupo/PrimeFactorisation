FINAL STRUCTURAL SUMMARY

For each shift c:

    M_c = n+c
    H_c = gcd(C,M_c)

and therefore:

    H_c | M_c
    H_c | C

The previous experiments used:

    L = lcm(H_c)

but L | C is only a necessary condition.

Experiment 692 instead emphasizes the exact condition:

    gcd(C,n+c) == H_c

for ALL shifts simultaneously.

The main question is:

    Can the complete shifted divisor information
    force a small set of self-consistent C values?

The strongest possible outcome would be:

    one surviving C
    -> frame equation
    -> p,q

A weaker but still useful result is:

    many C candidates remain,
    but the candidate count shrinks rapidly as shifts are added.

A failure would mean:

    shifted divisor lattices alone do not select C
