==============================================================================
1. POLYNOMIAL N-ONLY OBSTRUCTION
==============================================================================

For every integer polynomial G:

    G(n) == G(0) (mod n)

Therefore:

    gcd(n,G(n)) = gcd(n,G(0))

Examples:
n+1             value mod n = 1 gcd = 1
n-1             value mod n = 603888910784230 gcd = 1
n^2+n+1         value mod n = 1 gcd = 1
n^2-n+1         value mod n = 1 gcd = 1
n^3-1           value mod n = 603888910784230 gcd = 1
n^3+1           value mod n = 1 gcd = 1

CONCLUSION:
Pure polynomial substitution is mathematically exhausted.
