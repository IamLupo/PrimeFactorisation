    h_d(t)
      = A_d(u)
      + (2t+1) B_d(u),

    u=t(t+1).

The present experiment is aimed at the construction law of the
layer sequence itself.

The important object is now the pair of exact sequences

    A_16, A_14, A_12, ..., A_0

and

    B_15, B_13, B_11, ..., B_1.

We search for recurrences of the form

    c_0(u) H_r
      + c_1(u) H_{r-1}
      + ...
      + c_m(u) H_{r-m}
      = 0,

where every c_j(u) has small exact rational/integer degree.

A recurrence that survives every available transition is strong
evidence that the kernel is generated recursively.

A recurrence appearing only because the sequence is short is not
accepted as a universal law.

The key distinction remains:

    reconstruction:
        observed layer values -> t -> X -> N -> p,q

versus

    construction:
        kernel definition -> recurrence -> all layers.

The second is the structural target.

Fresh semiprime reconstruction is included only as an exact
consistency check.
